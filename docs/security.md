# 암호화 보관함

첫 실행에서 **8자 이상의 보관함 비밀번호**를 설정합니다. Mac 로그인 암호와 별개입니다. 브라우저에서도 이 비밀번호로 열 수 있습니다. 비밀번호는 로그, 환경 변수, 명령행 인수, 일반 설정 파일에 저장하지 않습니다.

Mac 앱에서 **Mac 키체인에 보관하고 본인 인증으로 열기**를 선택하면 로그인 키체인에 보관합니다. 이 로컬 빌드는 Apple 개발자 인증서 없이 서명하므로 파일 기반 키체인과 현재 앱만 신뢰하는 접근 목록을 사용합니다. 앱은 LocalAuthentication의 `deviceOwnerAuthentication`이 성공한 뒤에만 비밀번호를 읽습니다. Touch ID를 쓸 수 없으면 macOS가 제공하는 인증 방법을 사용합니다. 재설치로 앱 서명이 바뀌면 키체인 접근 확인이 다시 나타날 수 있습니다. 인증 취소나 키체인 오류가 나면 보관함 비밀번호로 열 수 있습니다.

## 저장과 잠금

- 녹음이 끝나면 WAV를 암호화해 보관합니다. 복호화한 복사본이 원본과 같은지 확인한 뒤 평문 임시 파일을 지웁니다.
- 받아쓰기, 요약, 파일 목록, 사용자 서식, 일괄 수정 규칙도 암호화합니다.
- AES-256-GCM을 사용합니다. 파일마다 무작위 128비트 salt와 HKDF-SHA256으로 별도의 키를 만들고, 1 MiB 단위로 인증해 오디오를 탐색합니다. 헤더, 상대 경로, 보관함 ID, 블록 순서도 인증합니다. 암호 알고리즘은 `cryptography` 라이브러리를 사용합니다.
- 무작위 256비트 보관함 키는 scrypt로 비밀번호에서 만든 키로 암호화해 `vault.json`에 보관합니다. 비밀번호와 평문 키는 이 파일에 들어가지 않습니다.
- 재실행하면 항상 잠깁니다. 세션은 메모리에만 있고 잠그면 모두 폐기합니다. 상태·파일 목록·다운로드 API도 세션을 요구합니다.
- 5분 동안 사용하지 않으면 잠깁니다. 화면 잠금·사용자 전환·절전 시 Mac 앱도 잠금을 요청합니다. 모델 작업 중에는 유휴 잠금을 미룹니다. 명시적인 잠금은 작업을 중단하고 저장을 마무리한 뒤 키를 해제합니다.
- 음성 인식과 다운로드는 암호화 파일을 메모리에서 읽습니다. STT를 위한 평문 디스크 사본은 만들지 않습니다.
- 결과 저장은 기본적으로 암호화 보관만 합니다. **일반 파일도 내보내기**를 선택하면 암호화가 해제된 TXT·MD를 별도로 저장합니다. 녹음 목록의 일반 음성 내보내기도 같은 원칙입니다.

## 기존 데이터와 백업

최초 설정이나 재개 시 기존 파일을 암호화한 뒤 내용 해시를 대조합니다. 검증이 실패하면 원본을 보존합니다. 이관 도중 종료되어 원본과 암호화 파일이 함께 남으면 다음 잠금 해제 때 검증을 재개합니다. 내용이 다르면 자동으로 덮어쓰거나 지우지 않습니다.

서버를 중지한 뒤 설치된 `data/` 전체를 백업합니다. **`vault.json`과 `.enc` 파일을 함께 보관해야 합니다.** 새 Mac에서도 보관함 비밀번호가 필요합니다. 키체인 정보가 옮겨질 것이라고 가정하지 마세요. 비밀번호와 키체인 접근을 모두 잃으면 복구할 수 없습니다.

## 보호 범위

이 기능은 **보관된 암호화 파일만 복사해서 가져간 경우**에 대비합니다. 다음은 보호 범위에서 제외합니다.

- 녹음 중인 `pending-recording.m4a`, 업로드·형식 변환 도중의 임시 파일. 비정상 종료 시 평문이 남을 수 있습니다.
- 가져온 파일의 원래 위치, 예전 소스 폴더의 `data/`, 과거 백업·스냅샷, 일반 파일로 내보낸 사본. 다른 위치의 파일은 자동으로 지우지 않습니다.
- 삭제한 평문의 저장 장치 잔여 흔적. 파일 삭제는 SSD의 물리적 완전 삭제를 보장하지 않습니다.
- 잠금 해제된 앱·Mac을 장악한 공격자, 프로세스 메모리, 화면·클립보드 내용.
- 파일 크기와 보관 파일 이름에 포함된 날짜·확장자, 일반 모델 설정·로그. 파일명과 크기를 숨기는 기능은 없습니다.

Mac 분실에 대비하려면 FileVault도 별도로 켜세요. 앱은 FileVault 설정을 자동으로 바꾸지 않습니다.

검증: `.venv/bin/python tests/vault-smoke.py`, `NODE_PATH=/tmp/azimuth-dom/node_modules node tests/dom-smoke.cjs`. 실제 모델 흐름은 `tests/smoke.py`로 확인합니다. 본인 인증의 성공·취소는 실제 사용자 상호작용이 필요합니다.

참조: [Apple AES-GCM](https://developer.apple.com/documentation/cryptokit/aes/gcm), [Mac 키체인](https://developer.apple.com/documentation/technotes/tn3137-on-mac-keychains), [LocalAuthentication](https://developer.apple.com/documentation/localauthentication/lacontext/evaluatepolicy(_:localizedreason:reply:)), [cryptography AEAD](https://cryptography.io/en/latest/hazmat/primitives/aead/).
